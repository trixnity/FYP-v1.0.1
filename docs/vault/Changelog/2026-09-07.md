# 2026-09-07

## Summary
Switched the deployment target from Railway to **Koyeb** (free tier) after the user
hit an unspecified error on Railway.

## Changes
- Deleted `railway.json`.
- `Dockerfile`: JVM flags for a ~512 MB free instance
  (`-XX:MaxRAMPercentage=70 -XX:+UseSerialGC`); comment de-Railway'd.

  pushes to `ghcr.io/trixnity/fyp-v1.0.1:latest` on push to `main` — a build path that
